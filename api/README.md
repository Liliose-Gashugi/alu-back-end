# API

This project uses a REST API to retrieve employee information and TODO list progress.

## Requirements

- Python 3
- Requests library

## Task 0: Gather data from an API

The Python script accepts an employee ID as an argument and displays:

- The employee's name.
- The number of completed tasks.
- The total number of tasks.
- The titles of completed tasks.

## Usage

```bash
./0-gather_data_from_an_API.py 2
